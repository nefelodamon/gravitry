# Gravitry

A small gravity game in plain HTML and JavaScript. Drop a particle among stars, black holes,
pulsars, white holes, comets and nebulae, and see how far it travels before it crashes or escapes.

**Play:** https://nefelodamon.github.io/gravitry/

- 36 levels, plus endless random layouts (choose what they contain in Options)
- A level editor, ghost runs of your best attempt, and share links that replay a run exactly
- Thruster nudges, slingshot launches, wormholes and slow motion on close fly-bys

No build step: open `index.html` in a browser, or serve the folder with any static web server.
Progress is saved in your browser's localStorage.
